# 🚀 Cardify (Study Desk & Flashcard)

Aplikasi web interaktif berbasis web untuk membantu proses belajar, meringkas catatan materi kuliah secara otomatis, membuat flashcard, mode kuis latihan soal, serta mencatat log progress mingguan.

## ✨ Fitur Utama
- **Ringkasan Catatan & Unggah File:** Mendukung teks, file `.txt`, `.md`, `.pdf`, `.docx`, dan `.pptx`.
- **Flashcard Interaktif:** Ubah catatan menjadi kartu hafalan dengan indikator progress belajar.
- **Mode Kuis Cerdas:** Latihan soal pilihan otomatis dari flashcard secara acak.
- **Log Progress Mingguan:** Catat target pengerjaan dan kendala tiap minggu lengkap dengan tombol salin untuk spreadsheet.
- **Mode Gelap (Dark Mode):** Nyaman digunakan di malam hari.
